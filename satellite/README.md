# 1U CubeSat — Elastic x Aerospace

A 3D-printed CubeSat prop that emits real CCSDS telemetry into the ground-station
stack. Live sensors, servo-deployed wings, IDS-alert LEDs, camera payload.

## Where things are

| Path | What |
|---|---|
| `build-guide/` | **Start here to build it.** 8 guides, printing through checkout. `OPEN-ITEMS.md` lists everything unverified |
| `build-guide/make-docs.sh` | Converts the guides to Word. `./make-docs.sh pdf` needs a PDF engine |
| `bom/` | `Satellite-BOM.xlsx` (orderable), `BOM.md` (rationale), `ORDER-LIST.md` (checklist) |
| `cad/*.py` | Parametric generators and renderers. Run from this directory |
| `cad/stl/` | Our 13 generated parts, all watertight |
| `cad/stl/frame/` | The 5 HC-Eleni frame parts, vendored so the print queue is one folder |
| `cad/renders/drawings/` | Dimension sheets 1-5, generated by measuring the STLs |
| `cad/renders/views/` | Shaded assembly views |
| `diagrams/` | Power and data wiring topology |

## Regenerating

```bash
cd cad
python gen_parts.py                 # -> stl/
python gen_panels.py                # -> stl/
python gen_dimension_drawings.py    # -> renders/drawings/
python render_assembly.py           # -> renders/views/  (prints the joint check)
```

Needs `trimesh`, `shapely`, `numpy`, `manifold3d`, `Pillow`.

## Two things gate the build

1. **The frame has no panel fixing holes**, and the X-face and Y-face patterns would
   intersect inside the 10 mm corner posts if drilled as drawn.
2. **The pedestal post's 2x M3 at 60 mm** may land on the base plate's 92 perforations.
   Do not print `pedestal_post` until this is checked.

Both are detailed in `build-guide/OPEN-ITEMS.md`.
