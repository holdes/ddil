# DDIL kit physical setup guide

Out of the case to powered on in seven steps, the indicator timeline after master power,
and the pack-down in reverse. Built on the kit lead's own steps (13 Nov 2026), with supporting
facts from `../FACTS.md`, the kit configuration runbook (`../docs/pdf/02-kit-configuration-runbook.pdf`),
the network and hardware docs, and the kiosk code. Software checks live in the runbook, not here.

## Rebuild

```bash
cd enablement/setup
python3 build.py            # index.html, ddil-setup-guide.html, print edition and PDF
python3 build.py --no-pdf   # HTML only
```

Needs Google Chrome. The PDF step needs PyMuPDF (`pip install pymupdf`) and Pillow, and the
hive-mind `hive-elastic-brand-pdf` scripts (set `HIVE_PDF_SCRIPTS` if hive-mind is not at
`~/Desktop/Elastic/hive-mind`).

## Swap the illustrations

1. Export each view with a transparent background at the **same framing** as the current files
   (about 1122 x 1402 px, the unit filling the canvas the same way). Hotspots are percentages of
   the image box, so the same framing keeps every hotspot in place.
2. Save as `img/front.png`, `img/back.png`, `img/side.png` (or `.webp`). The build takes the first
   file that exists in the order `.png`, `.webp`, `.jpg`; the paths are set in one block,
   `IMAGES` at the top of `build.py`, and the views and their Front/Back/Side tabs are listed in `VIEWS` beside it. To keep files small, convert with
   `cwebp -q 80 -alpha_q 90 -m 6 front.png -o img/front.webp` and leave no `img/front.png` behind.
3. Run `python3 build.py`. It rebuilds the single file with the new images inlined and refreshes
   the flattened print copies.
4. Open `index.html`, tap each step, and check the pink rings land on the right parts. If the
   framing changed, correct `x` and `y` in `src/hotspots.json` and rebuild.

## Deep links

`index.html#s4` opens with step 4 highlighted. `index.html?tip=B4` opens the back view with the
tooltip for hotspot B4. Checkbox ticks and filled-in blanks are saved in the browser's local
storage; "Reset checklist" clears ticks and keeps the blanks.

## Writing rules

Declarative sentences, no em dashes, no customer names, no secrets. Anything not in a source is a
visible "confirm on kit" blank. Never write the Wi-Fi passphrase into the shared files.
