# DDIL kit SA documentation

Branded documentation set for solutions architects who present the DDIL demo kit.
Every figure, name and endpoint comes from `../FACTS.md` (status as of 13 Nov 2026,
code basis commit `5114c3a`). Staged and doc-only values are labelled where an SA reads them.

## Layout of this folder

| Path | What |
|---|---|
| `src/*.html` | Page bodies. One `<div class="page">` per Letter page. `<!--foot-->` marks the footer; `<!--fig:NAME-->` inlines `figures/NAME.svg`. Edit these. |
| `src/style.css` | Shared stylesheet in the house deck style (eyebrows, blue second-half headlines, ink cards with offset shadow). Inlined into every document. |
| `html/*.html` | Generated. Self-contained: CSS inlined, Inter and IBM Plex Mono embedded from `../brand/fonts`, links `../../brand/tokens.css`. Do not edit by hand. |
| `pdf/*.pdf` | Generated by headless Chrome. |
| `figures/architecture.json` | Iso scene for the architecture figure. |
| `assets/logos/` | Copies of `../brand/logo/logo-elastic-horizontal-{dark-ink,white}.svg`, named so the hive preflight finds them. |
| `build.py` | Assembles HTML, runs preflight, renders and verifies the PDFs. |

## Rebuild

Requirements: Google Chrome, Python 3 with PyMuPDF (`pip install pymupdf`), and the
hive-mind checkout with the `hive-elastic-brand-pdf` skill. Set `HIVE_PDF_SCRIPTS` if
hive-mind is not at `~/Desktop/Elastic/hive-mind`.

```bash
cd enablement/docs
python3 build.py                        # all documents
python3 build.py 04-scenario-sec        # one document
python3 build.py --html-only            # assemble HTML only
```

For each document the script assembles `html/<name>.html`, numbers the footers, runs
`preflight.py` (stops on ERROR and prints every WARN), then runs `pdf_verify.py`, which
renders `pdf/<name>.pdf` and checks the bottom edge, DOM overflow and page count.

To change the architecture figure:

```bash
cd enablement/docs/figures
node ../../tools/elastic-iso-diagrams/render.mjs architecture.json -o architecture.svg
node ../../tools/elastic-iso-diagrams/png.mjs architecture.svg /tmp/arch.png   # inspect
cd .. && python3 build.py 01-architecture-guide
```

## Writing rules

- No figure without a FACTS.md entry. If FACTS.md marks it STAGED or DOC-ONLY, say so on the page.
- Declarative sentences. No em dashes. No customer names. No secret values; variable names only.
- Keep each page under the content budget. Preflight warns when a page carries more than
  two tables, or several code blocks and a section heading; split the page rather than ignore it.
- After FACTS.md changes, update the affected pages and rebuild. Re-check the "Known issues"
  box in runbook 02 and the status date on every cover.
