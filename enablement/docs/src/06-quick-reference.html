  • _cat/indices: record vineyard, sec_10k_2026, jina-multimodal, pmc-unstructured counts.

Shutdown, in reverse order

  1. Framework: cd ~/ddil/demo && docker compose down, then sudo shutdown -h now.
  2. Spark: Ctrl-C the Jina server, cd ~/ddil/docker && sg docker -c "docker compose down", then sudo shutdown -h now.
  3. Switch and gateway last.
