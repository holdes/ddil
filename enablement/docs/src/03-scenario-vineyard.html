Vineyard Intelligence. The agronomist in the case.

Presenter runbook for the Vineyard adventure: audience, story, pre-show checks, a timed click path, exact prompts, likely questions, failure recovery and reset.

Suggested length 12 to 18 minutes Status as of 13 Nov 2026 Code basis: commit 5114c3a
Audience and outcome

For operators and technical buyers who need analysis close to sensors and data that cannot leave the site: agriculture, field operations, expeditionary units.

They leave knowing that Elasticsearch and NVIDIA Nemotron 3.5 Lightning on two local nodes can query years of sensor history, find similar past conditions by vector search, and produce a reasoned action plan with no network.

The story in three sentences

Domaine de la Côte Cachée is a fictional estate in the Walla Walla AVA with six blocks and eight years (2018 to 2025) of synthetic sensor, nutrient and harvest data.

Block C, La Rivière, has declined since a drainage failure in mid-2022 that pulled soil potassium from 210 toward a 50 mg/kg floor.

The AI Agronomist finds that story by querying Elasticsearch on the kit and reasoning over the results with Nemotron 3.5 Lightning on the DGX Spark.

Three things to remember
  • The indexing race is a timed simulation. Say so before it starts.
  • The AI Agronomist is a Python pipeline with live ES queries and live LLM calls. It does not use Agent Builder.
  • Skip Search, Crop Health and System.
About the numbers

Block acres sum to 21.6. The chooser says "22 acres". Say "about 22 acres". The data is synthetic, generated with a fixed seed from one causal model.

Timing reality

Four model calls run one after another, each with a 120 s timeout. No measured timing is recorded for the kit; the times above are pacing targets. The worst case is about 8 minutes. Plan the session so the investigation can run long without breaking the story, and never start it on a cold model.

03 · Vineyard IntelligencePrompts and questions
Suggested prompts, quoted from the UI

Use these words exactly.

AI Agronomist chips

  • Why is La Rivière (BLK-C) underperforming since 2022?
  • Why was the 2020 Clos du Vent Syrah our best wine despite the drought?
  • Which blocks are at risk for disease this season?
  • What's happening with potassium levels in Block C?
  • Compare Block E (Vieilles Vignes) consistency across all vintages
  • What should I prioritize this week across the estate?

Dashboard "Quick Investigate"

  • Why is Block C underperforming?
  • Compare the 2020 and 2022 vintages
  • Which blocks need attention this week?
  • What caused the potassium cliff in La Rivière?
  • Show me the best performing block and explain why

Chips and typed questions carry no block. Map, Dashboard block and sidebar "Investigate" entries do. Prefer the map entry for BLK-C.

Likely questions
QuestionAccurate answer
Is this Agent Builder?No. This is a five-phase pipeline in the demo backend that queries Elasticsearch and calls the model directly. The SEC adventure shows Elastic Agent Builder with ES|QL tools. A Vineyard agent design exists in the project notes but is not provisioned on this kit.
Is the data real?It is synthetic, generated by one causal model (weather, soil, nutrients, disease, harvest, wine) for 2018 to 2025 with a fixed seed. The stories, such as the 2020 drought and the BLK-C drainage failure from 15 June 2022, are built into the generator.
How many records?Quote the counts you recorded in the pre-show check. Do not quote 869K or 841K from the screens.
Which model? Does anything leave the kit?NVIDIA Nemotron 3.5 Lightning on Ollama on the DGX Spark. Elasticsearch and the model both run on the kit; no call in this adventure leaves it.
What does the vector search use?An 8-dimension reading_vector per soil reading, cosine similarity, k=5 from 100 candidates, filtered to the block. In this build the query vector uses the current moisture and temperature; the other four dimensions are fixed values.
Did the model know the story in advance?Partly. Its system prompt describes the estate and the size of the data sets. The readings, the similar history and the analysis come from live queries during the run.
How fast was GPU indexing?The race is a simulation and gives no measured figure. Offer Elastic's published cuVS material as a follow-up.
Why does it take minutes?Four model calls run in sequence on local hardware. That is the cost of keeping inference on site.
Can it read leaf images?The Crop Health screen is a design mock and returns a fixed result. The imagery index is not loaded by the repo's load script.

Reset

Between audiences

  1. Click "Reset Demo" in the sidebar. It clears the scene, the selected block, the pending query and the vineyard-conversations history, and returns to the chooser.
  2. Optionally reset the server race state: press Reset on the race screen or curl -X POST http://192.168.1.10:8000/api/race/reset. The next race start also reinitialises it.
  3. Reload the browser tab.
  4. If more than a few minutes will pass, warm the model again before the next investigation.
